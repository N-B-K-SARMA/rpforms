# Contributing to RPForms

First off, thank you for considering contributing to RPForms! 

## Branch Naming
- `feat/feature-name`
- `fix/bug-name`
- `docs/doc-update`
- `chore/maintenance`

## Commit Style
We follow conventional commits:
- `feat: added a new form feature`
- `fix: resolved crashing issue on startup`
- `docs: updated README.md`

## Pull Requests
1. Fork the repo and create your branch from `main`.
2. Ensure you have run `npm run lint` and `npm run build`.
3. Submit a PR describing your changes.

## Coding Standards
- We use ESLint and Prettier. Run `npm run format` before committing.
- Ensure strict TypeScript typings are used.
