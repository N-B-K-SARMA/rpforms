## Overview

RPForms is a highly configurable, professional Discord application framework. It allows roleplay servers (FiveM, RedM, etc.) to build modern application systems without needing to write custom code. 

## Features

- **Dynamic Forms**: Fully configurable questions and modals.
- **Application Flow**: Support for multi-step applications.
- **Staff Reviews**: Dedicated channels for staff to review, approve, or reject applications.
- **Logging**: Comprehensive action and review logs.
- **Role Management**: Automatic assignment of roles upon approval.
